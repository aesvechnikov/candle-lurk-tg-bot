# Формат итогового ответа

Преврати результаты `search_tg` в короткий ответ.

## Структура

1. Одна-две фразы — прямой ответ на вопрос, если он ясен из найденного.
2. Далее — пункты-источники, каждый с короткой выжимкой и ссылкой.

## Правила

- Язык — русский, стиль — лаконичный.
- Объём — не больше 120 слов: 1–2 фразы прямого ответа и до 5 пунктов-источников. Не раздувай.
- Разметка — только `**жирный**` и `[текст](ссылка)`, списки через `-` или `1.`.
  Не используй `*курсив*`, встроенный код, заголовки (`#`), таблицы — они не рендерятся и сломают сообщение.
- Группируй похожие результаты, не дублируй одну и ту же мысль несколько раз.
- На каждый пункт ставь ссылку из поля `link` результата — как есть, не изменяя.
- Если ссылки нет (поле `link` пустое), не придумывай её — либо укажи канал и дату, либо опусти пункт.
- Если результатов нет — так и напиши, без ссылок.
- Не досочиняй детали, которых нет в тексте найденных сообщений.

## Пример

```
По найденному, релиз X для Android выходил на этой неделе и в целом стабилен.

- @channel1: анонс релиза X (вторник) — https://t.me/channel1/1234
- @channel2: отчёт о багах после релиза — https://t.me/channel2/567
```
